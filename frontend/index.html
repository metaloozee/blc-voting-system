How to demo (Hardhat)

  1. Terminal 1: npx hardhat node
  2. Terminal 2: npx hardhat run scripts/deploy.js --network localhost
  3. Serve this folder: npx --yes serve frontend -p 3000
  4. MetaMask → add network localhost http://127.0.0.1:8545, chainId 31337
  5. Import a Hardhat private key from the node output, then Connect → Vote
  6. Import Account #0 (owner) to End Election and view the winner
